# ADR-003 — A regra vive na base; a API é a porta do sensível

- **Estado:** aceite (2026-10-18, `docs/plan/architecture.md` §10); ficheiro criado no passo C (2026-10-25).

## Contexto

o inventário mostrou uma camada de dados que deixava o browser escrever tudo.

## Decisão

regras de negócio em funções SQL; escritas com estado, dinheiro ou outra pessoa passam pela API com `service_role`; o cliente só escreve o que é seu, por concessão de coluna.

## Consequências

mais rotas na API; uma regra tem um só sítio.
