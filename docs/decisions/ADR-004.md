# ADR-004 — Schema recomeçado de raiz

- **Estado:** aceite (2026-10-18, `docs/plan/architecture.md` §10); ficheiro criado no passo C (2026-10-25).

## Contexto

o `database_schema.sql` antigo nunca correu de uma só vez, não tem RLS nem migrations, e diverge do código em 18 pontos (inventário).

## Decisão

o schema é desenhado de novo em `packages/db`, a partir de `data-model.md`; a base remota antiga não é tocada.

## Consequências

a camada de dados antiga não se migra; os ecrãs sim.
