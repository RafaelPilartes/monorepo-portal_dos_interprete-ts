# ADR-001 — Monorepo pnpm + Turborepo

- **Estado:** aceite (2026-10-18, `docs/plan/architecture.md` §10); ficheiro criado no passo C (2026-10-25).

## Contexto

quatro apps e uma API sobre a mesma base, com tipos e componentes partilhados.

## Decisão

monorepo pnpm + Turborepo.

## Consequências

um só lockfile; os pacotes partilhados não se publicam; o CI e o hook local correm em todo o repositório.
