# ADR-005 — Pagamentos por comprovativo

- **Estado:** aceite (2026-10-18, `docs/plan/architecture.md` §10); ficheiro criado no passo C (2026-10-25).

## Contexto

o Multicaixa Express exige homologação EMIS de semanas.

## Decisão

transferência com comprovativo validado pela equipa, atrás de uma intenção de pagamento genérica, preparada para receber um gateway depois (`FP-03`).

## Consequências

trabalho manual do financeiro; nenhum webhook nesta corrida.
