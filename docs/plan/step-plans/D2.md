# Step D2 — Move `admin-web` Implementation Plan

> Executed inline in continuous mode; independent review at the end of the step.

**Goal:** every admin route of `docs/inventory/05-route-map.md` opens in `apps/admin-web` at its new path (`architecture.md` §3, admin table) with the same content as today, no console errors.

Its two view models become local stubs with the same signatures, backed by `teamMocks`-shaped fixture data; writes reject with a Portuguese message saying team management arrives with the database (step H1). Recorded as AD-010.
