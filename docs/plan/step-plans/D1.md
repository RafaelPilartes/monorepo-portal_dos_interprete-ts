# Step D1 — Move `site-web` Implementation Plan

> Executed inline in continuous mode (`docs/plan/claude-code-rules.md` §6); independent review at the end of the step.

**Goal:** every site route of `docs/inventory/05-route-map.md` opens in `apps/site-web` with the same content as today (mocks included), no console errors, and a Portuguese 404 that is reachable.

**Architecture:** move, don't rewrite (`foundation.md` §D). Site-only pages and components move into `apps/site-web/src`. What more than one audience uses goes up now: domain-free pieces (shadcn primitives, `cn`, toast hooks, theme provider, `FiltersBar`, design tokens CSS) to `packages/ui`; domain pieces (`InterpreterCard`, the four public interpreter-profile pages, `VideoModal`, the interpreter mocks) to `packages/features`; the three entry pages (login, register, recover password) to `packages/auth`. The site links to them in `requester-web` through `VITE_REQUESTER_URL` (AD-006 ports).

**Spec:** `docs/plan/specs/foundation.md` §D; `docs/plan/architecture.md` §3 (`site-web` table); `docs/inventory/05-route-map.md`.

## Global Constraints

- Strict TypeScript errors revealed by the move are fixed only in moved files, without behaviour change; anything needing a behaviour change is recorded in `auto-decisions.md`.
- Moved files keep their content except: import paths, cross-app links, and strict-mode fixes.
- `legacy/` stays intact until D4.
- Links from the site to pages that left it: `/login`, `/register` → `${VITE_REQUESTER_URL}/login|/register`; an interpreter card → `${VITE_REQUESTER_URL}/login?returnTo=/interpreters/<slug>` (`architecture.md` §3, D-05).
- `/home` redirects to `/` (old URL kept working); `*` renders the Portuguese `NotFound`.

## Review Focus

1. A route that renders an empty `#root` (runtime import error) — caught by the Playwright smoke test (fails on blank page or console error).
2. Old `/home` bookmarks — redirect to `/`.
3. Unknown URL — Portuguese 404, not a redirect to home (`04-gaps.md` item 29).
4. Interpreter card clicked on the site without session — goes to the requester login with `returnTo`.
5. Fonts/images from external hosts blocked in the VM — not counted as page errors (network failures are filtered; JS errors are not).
